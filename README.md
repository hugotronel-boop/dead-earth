# DEAD EARTH V2.4 LIGHT — BASE REPLIABLE

Le menu Base utilise désormais 10 panneaux déroulants. Ils sont tous fermés au départ pour une interface plus compacte : Protection du village, Zone sécurisée, Améliorer le refuge, Constructions de survie, Surveillance du refuge, Réserve de stockage, Infirmerie électrique, Station radio, Production & électricité, Atelier d’armes.

Appuie sur un titre (flèche ▼) pour déplier ou replier son contenu. Plusieurs panneaux peuvent rester ouverts simultanément. Les boutons et les règles du jeu de la V2.3 sont conservés : construction, stockage, générateur, électricité, armes et missions.

Installation GitHub Pages : remplacer uniquement index.html à la racine du dépôt DEAD EARTH. Le jeu utilise la même sauvegarde locale qu'avant.

Tests : 10 rubriques vérifiées sur émulation de largeur mobile, ouverture/fermeture et données des constructions ; absence d'erreurs JavaScript lors des tests en navigateur. Les tests ont été réalisés en environnement de développement, pas sur iPhone réel.
